## Repository Guidelines

1. **Keep it Markdown-Native:** All procedures must use standard Markdown formats so they can be read directly on GitHub/GitLab.
2. **Include Rollbacks:** Every migration or upgrade procedure must include backup instructions before execution.
3. **Paths Matter:** Always specify explicit system directories.
